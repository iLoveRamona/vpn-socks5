# vpn-socks5

Docker-контейнер, который подключается к VPN по OpenVPN и поднимает SOCKS5-прокси (Dante). Приложения на компьютере подключаются к прокси, и их трафик уходит через VPN, а остальная система остаётся вне туннеля.

```
приложение --> SOCKS5 127.0.0.1:1080 --> [контейнер: sockd --> tun0 --> OpenVPN] --> интернет
```

## Требования

- Docker и Docker Compose
- Конфиг клиента OpenVPN (`.ovpn`) и сертификаты/ключи

## Установка

1. Создать папку `vpn/` рядом с `docker-compose.yml` и положить в неё файлы:

   ```
   vpn/
   ├── client.ovpn
   ├── ca.crt
   ├── client.crt
   └── client.key
   ```

   Если сертификаты встроены в `.ovpn`, отдельные файлы не нужны.

2. Проверить пути в `client.ovpn`. Они должны быть относительными (`ca ca.crt`) или начинаться с `/vpn/`.

3. Если VPN требует логин и пароль, положить в `vpn/` файл `auth.txt` (первая строка: логин, вторая: пароль) и указать в `client.ovpn`:

   ```
   auth-user-pass auth.txt
   ```

## Запуск

```bash
docker compose up -d --build
```

Остановка:

```bash
docker compose down
```

## Проверка

```bash
docker compose logs -f
curl --socks5-hostname 127.0.0.1:1080 https://ifconfig.me
```

## Использование

Указать в приложении SOCKS5-прокси:

- Хост: `127.0.0.1`
- Порт: `1080`
- Авторизация: не требуется
